Reglas del sistema / System rules

  • Rejilla / Grid24×24, área de contenido nominal 20×20 (padding óptico 2 unidades; 11/57 excepciones declaradas en D-09 §6.1). Prueba de reducción 16/24/32 escalando el maestro de 24, sin variantes de 16 rediseñadas y sin 48 px (ver tablero). Nominal 20×20 content area (2-unit optical padding; 11/57 declared exceptions in D-09 §6.1). 16/24/32 reduction proof scales the 24 px master; no redesigned 16 px variants and no 48 px.
  • Trazo / Stroke2 px en la rejilla de 24 (2 px equivalente). Extremos y uniones redondos en UI; extremos rectos en diagramas técnicos. Round caps and joins in UI; butt caps in technical diagrams.
  • Esquinas / CornersRadio lógico 1,5 px; rectángulos con rx 1,5–2. Geometría corregida ópticamente, no matemáticamente. Optical centring, consistent counters.
  • Relleno / FillContorno por defecto. Relleno solo para estado seleccionado/activo, forma de alarma sólida o marcas de nivel (barras de señal, puntos). Outline by default; fill only for selected/active state, solid alert shape or level marks.
  • Color / ColourLos iconos heredan currentColor; nunca multicolor. El estado se refuerza con forma + etiqueta + icono, nunca solo color. Icons inherit currentColor; never multicolour. State is reinforced by shape + label + icon, never colour alone.
  • Etiquetas / LabelsControles críticos siempre icono + texto; sin alarma ni acción de seguridad solo-icono. Siluetas con IoU > 0,80 se emparejan siempre con texto. Critical controls always icon + text; no icon-only alarm or safety action. Silhouettes with IoU > 0.80 always pair with text.

Uso semántico de color y forma / Semantic colour and shape use

El color es un rol, no decoración. Cada estado conserva icono, forma y etiqueta: en escala de grises debe seguir siendo identificable. Colour is a role, not decoration. Every state keeps icon, shape and label: it must remain identifiable in greyscale.

  • Información / Info (advisory)Información / aviso; sin carga de seguridad. / Info / advisory; no safety implication.
  • Precaución / CautionTriángulo + «!». Nivel 2; nunca solo color. / Triangle + “!”. Level 2; never colour-only.
  • Advertencia / WarningTriángulo con segundo borde + «!». Nivel 3; causa y acción obligatorias. / Double-bordered triangle + “!”. Level 3; cause and action required.
  • Alarma / AlarmOctágono sólido + «!» recortado. Nivel 4; nunca se autodescarta. / Solid octagon + cut-out “!”. Level 4; never auto-dismissed.
  • Acuse de recibo / AcknowledgeAcuse ≠ resolución: la condición sigue visible hasta que cesa. / Acknowledge ≠ resolution: the condition stays visible until it clears.
  • Dato obsoleto / Stale dataObsoleto: valor atenuado, contorno discontinuo y edad visible. / Stale: attenuated value, dashed outline and visible age.
  • Sin conexión / OfflineSin conexión: banner persistente y «último conocido» con edad. / Offline: persistent banner and “last known” with age.
  • Sin datos / No dataSin datos: guion y etiqueta; nunca un cero. / No data: em dash and label; never a zero.
  • Desconocido / UnknownDesconocido: estado distinto de obsoleto y de sin datos. / Unknown: a state distinct from stale and no-data.
