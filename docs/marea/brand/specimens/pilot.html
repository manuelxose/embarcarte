4. Qué faltaría antes de afirmar capacidad / What would be needed before any capability claim

Compuerta de comercialización PILOT: BLOCKED. No existe evidencia de banco ni de mar, ni caso de seguridad, ni hardware fail-safe verificado. Antes de cualquier afirmación de capacidad se requiere, como mínimo:

  • Diseño de hardware congelado: BOM, esquemáticos, mazo, envolvente, arquitectura de potencia y selección de E-stop/contactor (G1).
  • Evidencia fail-safe independiente: corte de potencia verificado, watchdog de hardware, E-stop con canal monitorizado, release manual (G2).
  • Caso de seguridad de software, toma manual y plano de control autenticado (G5).
  • Registros firmados de banco y comisionado: tiempos de corte, disparo de sobrecorriente, E-stop bajo carga (G6).
  • Pruebas de mar por modo con inyección de fallos (G7).

Sin estos artefactos no se puede marcar PILOT como listo para venta, «turnkey» o con afirmaciones de prestaciones. / Without these artefacts PILOT cannot be marked sale-ready or marketed with steering-performance claims.

Autoridad humana: el sistema exige vigilancia continua y capacidad de toma de control manual en todo momento. El acuse de una alarma no sustituye la supervisión. The system requires continuous watchkeeping and manual takeover at all times; acknowledging an alarm does not replace supervision.

PILOT. «El sistema de gobierno es asistido y supervisado: exige vigilancia y capacidad de toma de control manual en todo momento. No permite gobierno autónomo ni control remoto sin supervisión.»

Navigation notice. “This product is a navigational aid. It does not replace official nautical charts, the vessel’s required equipment, continuous watchkeeping or good seamanship. Responsibility for navigation always rests with the skipper.”
