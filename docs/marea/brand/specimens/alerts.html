1. Escala de severidad — cuatro niveles / Severity ladder — four levels

El nivel nunca se comunica solo por color: forma + icono + etiqueta + texto. Toda alerta lleva causa, acción requerida y fuente/edad.

Nivel 1 · Aviso / Advisory · descartable, caduca si cesa · sin acuse

Acción requerida / Required action: revisar el aparejo y reducir la exposición al viento.

3. Estados de dato — mismo valor, siete estados / Data states — same value, seven states

La profundidad inventada de ejemplo es 12,4 m. Cada estado cambia el tratamiento visible; nunca se presenta un valor obsoleto como actual y nunca se sustituye «sin datos» por un cero.

Límites / Limits

  • Página ilustrativa y no funcional: niveles, causas, acciones, edades y fuentes son inventados; no hay sensores ni barco.
  • Sin prueba de hardware (pantalla marina, sol, sal, guantes, halación nocturna) y sin prueba de impresión 1:1.
  • Contraste: valores de rol del token file propuesto; esta página no mide el render. No se afirma conformidad WCAG de producto.
  • Contenido ES/EN; las alertas de nivel 3–4 usan role="alert", las de nivel 1–2 role="status". El acuse no oculta la condición.
