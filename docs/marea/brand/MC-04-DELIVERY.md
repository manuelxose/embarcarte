### 4.1 Construction consistency — defect found during the freeze and corrected before delivery

The first frozen master set was built on construction **C** while the recorded preference was **B**.
Governance found it during binding and the independent reviewer confirmed it as **IR-13/MAJOR**:
`marea-lockup-*`, `marea-mark-compact`, `marea-mark-reduced-16` and the nine family lockups carried the C
symbol, and two generated evidence artefacts still stated "C — PREFERRED_PROVISIONAL" with obsolete
scores (3.55/3.68/3.85). Both defects were fixed **before** this delivery was accepted, generator-first:
the master set was reissued from the B construction and the generated evidence was regenerated from
`territories/tools/build.mjs` / `render-reading-test.mjs` (now 3.48 / 3.68 / 3.58, B preferred, C
recorded as failing the small-size reading test, A dropped). They were then re-measured, re-rendered and
re-bound.

Reissued B master measurements (real Chromium `getBBox`, 32 files, 0 failed checks): lockup viewBox
**704.83×200**; symbol ink **98.87×100** exactly on the cap band 50…150 with the symbol bottom on the
baseline; wordmark **430.96×100**; ink gap **75.00** (0.75 cap); clear space **50** on all sides; compact
mark 32×32 with ink 29.66×30.0; reduced-16 with its own 16-unit coordinates (ink 15.47×15.3); family token
70.00 (0.70 cap) with a 26-unit word space (0.26 cap); nine family lockups from one rule, no per-family
symbol. The symbol stroke-weight question was settled with evidence rather than taste: 16 % was the wrong
target for a curved form, 8.6 % read thin and 14.3 % read letter-heavy ("G"); 3.2 units = **10.4 %** of
ink height was adopted and recorded with both rejected values in `IDENTITY-SYSTEM.md` §2.2/§4.1.

Consequence for the record: the delivered D-02/D-03 set now **is** built on the preferred construction
**B**; construction **C** remains documented as the shortlisted alternative that fails the small-size
reading test (bar chart/equaliser) and A remains the dropped territory. This is still an internal,
provisional identity: no adoption, no clearance, no publication.
