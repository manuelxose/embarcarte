2. Geometry specification

Grid 24 × 24 units; 1 unit = 1/24 mark height
Primary structure 4 open depth contours, each struck from its OWN centre (1,21) (3.5,23) (6,25) (8.5,27), centres offset on one slope line so the group is not concentric
Stroke 1.6 units (contour band), constant
Radial intervals 3.5 / 4 / 4.5 units — deliberately unequal
Ends radial cuts from −88° to −24°; the end cuts are staggered, not aligned
Anchor the innermost contour ends in a 1.6-unit measured datum on the wordmark baseline (y = 23.9)
Detail sounding square 1.4 units in the contour gap; dropped in the 16 px build
16 px build 3 contours, stroke 2.2/16, datum retained, square dropped
Optical corrections the non-concentric construction removes the radiating-signal reading of a concentric contour set; the datum overlaps the contour end by 0.4 units to avoid a hairline seam
