## 1. Method and commands

```text
npm run build:landing:preview        # exit 0
npx playwright test -c playwright.landing.config.ts
                                      # 44 passed / 44, exit 0 (full suite)
npx playwright test -c playwright.landing.config.ts \
  --grep '@visual' --update-snapshots # 8 baseline PNGs generated, exit 0
```

The responsive spec loads each width/locale combination fresh after hydration and
asserts page-level overflow (`documentElement.scrollWidth <= clientWidth + 1`),
banner and hero visibility, 9 family + 6 bundle cards, visible material
limitations, and the architecture scroll region. Screenshots are full-page,
`animations: "disabled"`, `caret: "hide"`, `scale: "css"`, deviceScaleFactor 1.
The visual spec re-captures the same eight viewports and compares them with
Playwright's snapshot comparer (`maxDiffPixelRatio: 0.001`).

## 4. Repeatability and pixel comparison

- **Pixel comparison: 8/8 captures compared against baselines, 0 mismatches**
  (`maxDiffPixelRatio 0.001`).
- **Byte-identical repeat captures: 3/8.** Five viewports (ES 768, ES 1440,
  EN 390, EN 768, EN 1440) produced a second capture with a different SHA-256.
  This is recorded in `summary.unstableCaptureDetails` (both hashes) rather than
  hidden; the committed image is the first capture. The differences are
  sub-threshold (the same viewports pass the pixel comparer), consistent with
  compositor anti-aliasing, but this dataset does **not** claim byte-stable
  screenshots for those viewports.
- Two EN baselines (390, 768) have a different SHA-256 from the committed
  capture while still passing the comparison; the baseline hash is recorded in
  the JSON.

## 6. Untested combinations and limitations

- Chromium only; **Firefox and Safari were not executed**.
- No real mobile hardware, touch input, virtual keyboard, orientation change or
  OS/browser text scaling (200%) in this dataset.
- Screenshots are from a development build on loopback (unminified; source maps
  present), at deviceScaleFactor 1; high-DPI and production/CDN rendering differ.
- Visual baselines are generated evidence, not a design review; any later CSS
  change must regenerate baselines and be re-reviewed.
- Full-page screenshots can differ in sub-pixel anti-aliasing between captures;
  repeat instability is recorded, not masked.
